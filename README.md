# Moai Idle Game (모아이 키우기)

- Unity로 개발한 2D 방치형 Merge 모바일 게임입니다.  
- 전작 팀 프로젝트 이후 개인 프로젝트로 제작했으며, 전투 중심 구조에서 벗어나  
  캐릭터 수집과 성장에 초점을 둔 방치형 게임으로 설계했습니다.

- 동일한 캐릭터를 합성(Merge)하여 성장시키고, 자동으로 골드를 획득하며  
  다양한 캐릭터를 수집하는 것을 주요 목표로 합니다.

## ⚙️ 주요 구현 기능
- 캐릭터 수집 중심 Merge 성장 시스템  
- 대량 캐릭터 데이터를 고려한 JSON 저장 / 로드 구조  
- 오프라인 보상 시스템  
- 일일보상 및 업적 시스템을 통한 플레이 동기부여  
- 자동 골드 획득 및 성장 로직  
- UI 자동 갱신 시스템  
  
---

## 🔍 전작 대비 개선 및 차별점
- 캐릭터 수 대폭 확장 → 수집 요소 강화  
- 미니게임 비중 축소, 수집/성장 루프에 집중  
- 보스 스테이지 제거, 전투 스트레스 완화
