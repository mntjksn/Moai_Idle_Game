# Moai Idle Game (모아이 키우기)
기존 팀 프로젝트로 개발했던 Merge 기반 방치형 게임을 개인 프로젝트로 리빌딩한 프로젝트입니다.
플레이 루프와 시스템 구조를 재구성하고, 콘텐츠 확장과 모바일 최적화를 중심으로 개선했습니다.

## 프로젝트 개요
- 개발 환경 : Unity 2D
- 사용 언어 : C#
- 개발 기간 : 2025년 06월 ~ 2025년 11월
- 개발 인원 : 1인 (개인 프로젝트)
- 플랫폼 : Android (Mobile)

## 전작 대비 개선 및 차별점
- 캐릭터 수 확장 → 수집 요소 강화
- 미니게임 비중 축소 → 성장 / 수집 루프에 집중
- 보스 스테이지 제거 → 전투 부담 완화
- 일일 보상, 업적, 오프라인 보상 추가 → 재접속 동기 부여
- 자동 소환 / 자동 합치기 기능 추가 → 반복 조작 피로도 감소

## 기술적 고민
### 1. 반복 생성 오브젝트 최적화
- 캐릭터, 골드 텍스트, 보상 이펙트처럼 반복적으로 생성되는 오브젝트가 많아질수록 성능 저하가 발생할 수 있었습니다.
- 이를 줄이기 위해 Object Pooling을 적용하여 오브젝트를 미리 생성하고 재사용하는 구조로 변경했습니다.
### 2. PlayerPrefs 한계
- 데이터 관리를 JSON으로 처리

## 회고
### 주요 어려움
 - 팀 프로젝트에서 구현했던 구조를 개인 프로젝트로 다시 만들면서, 단순히 기능을 추가하는 것보다 기존 구조를 개선하는 과정이 더 중요했습니다.
 - 콘텐츠가 늘어날수록 저장 데이터, UI 갱신, 오브젝트 생성 흐름을 일관되게 관리하는 부분이 어려웠습니다.
### 배운 점
- 반복 생성되는 오브젝트는 초기 단계부터 풀링 구조를 고려하는 것이 중요하다는 점을 배웠습니다.
- 기능을 확장하기 전에 데이터 구조와 시스템 책임을 먼저 분리해야 유지보수가 쉬워진다는 점을 경험했습니다.

- 기능 추가 시 기존 코드에 영향을 최소화하는 구조 설계의 중요성 인식을 가질 수 있었습니다.
- 대량 데이터 저장을 고려한 JSON 구조 설계 경험을 쌓았습니다.
- 반복 플레이를 유도하는 게임 루프 설계 경험을 쌓았습니다.
